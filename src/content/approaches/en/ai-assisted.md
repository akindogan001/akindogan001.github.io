---
title: AI-assisted development
question: How do you keep quality while building fast with AI?
order: 6
patterns:
  - name: Definition first
    desc: I define the requirements and the architecture before AI writes anything, so it works inside a clear frame and clear boundaries.
  - name: Project rules and brief files
    desc: Positioning, architectural rules and working preferences live in a persistent file inside the project, so every session starts from the same frame.
  - name: Decisions stay human
    desc: I make the architectural and product decisions; AI writes most of the code.
  - name: Review and test
    desc: Generated code is not accepted until it has been reviewed and verified with builds and tests.
---

For me, AI is a production tool, not a code generator to try things at random. My experience with .NET, React and TypeScript lets me judge the code it produces. On platforms I had not worked with before, the same discipline lets me ship quickly and in a controlled way.
